# Palette's Journal

## 2025-05-23 - Skip to Content Link
**Learning:** Even well-structured semantic HTML sites often miss the "Skip to Content" link, which is critical for keyboard users to bypass repetitive navigation.
**Action:** Always verify the existence of a skip link as the first item in the body, even if `<main>` is used correctly.

## 2025-05-24 - External Link Indicators
**Learning:** Users often click external links expecting them to open in the same tab, leading to confusion when a new tab opens. Standardizing this behavior with a visual indicator (" ↗") and `target="_blank"` improves predictability.
**Action:** Automatically append an external link icon to all links that open in a new tab, ensuring consistent user expectations.
